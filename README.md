# Razom.ch

A news portal for the Ukrainian community in St. Gallen, Switzerland.

🔗 [razom.ch](https://razom.ch)

## Overview

Razom.ch delivers news, articles, and event listings relevant to Ukrainians living in the St. Gallen region, with dedicated page formats for different types of content.

## Tech Stack

- **Frontend:** Next.js (App Router), TypeScript
- **CMS/Backend:** Strapi v5
- **Database:** PostgreSQL
- **Deployment:** Netlify
- **Internationalization:** next-intl

## Features

- Articles with dedicated pages
- Events section with its own page format
- Multi-language support
- Responsive UI with mobile-friendly navigation patterns
